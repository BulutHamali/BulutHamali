## Selected work

### [Reproducell ↗](https://scrna-reproducell.buluthamali.com/)

A family of scientific analysis platforms connecting quality control, biological interpretation, and exportable workflow records. Built around a clearer path to reproducible results.

Python · Scanpy · React · AWS · Nextflow

### [Drug Discovery Target Prioritization ↗](https://drugtargets.buluthamali.com/)

A leakage-safe ML workflow combining population genetics and functional genomics. Prospective evaluation produced **5.59× enrichment in the top 1% of ranked genes** against a later clinical-phase release.

Python · AWS Batch · XGBoost · Nextflow · Terraform

### [ResearchGapFinder ↗](https://researchgapfinder.buluthamali.com)

An AI pipeline for surfacing scientific knowledge gaps from biomedical literature, with a model-agnostic interface supporting Groq, Anthropic, and Ollama.

Python · NLP · LLM workflows
