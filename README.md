## Featured Work

### [scRNA-Reproducell](https://scrna-reproducell.buluthamali.com/)

Reproducibility-first single-cell RNA-seq analysis platform for QC, clustering, UMAP, marker discovery, and manifest-backed exports. Every parameter and software version is captured in a run manifest.

`Python` `Scanpy` `React` `AWS` `Nextflow`

### [Drug Discovery Target Prioritization](https://drugtargets.buluthamali.com/)

Leakage-safe machine learning pipeline combining population genetics, functional genomics, and clinical-phase labels to rank druggable targets. Prospective evaluation produced 5.59× enrichment in the top 1% of ranked genes against a later clinical-phase release.

`Python` `AWS Batch` `Nextflow` `XGBoost` `Terraform`

### [BioSignal Radar](https://biosignal-radar.vercel.app)

Full-stack trend detection platform that surfaces emerging bioinformatics research from bioRxiv preprints using Claude API, PubMed, and GitHub signals.

`Next.js` `Claude API` `Python` `Vercel`

### [ClinPilot](https://clinpilot.buluthamali.com)

Multi-agent clinical trial analysis platform using CrewAI and Anthropic’s Claude API, with cost-optimized orchestration and email notifications.

`CrewAI` `Anthropic API` `Python` `Streamlit`

### [Phrased](https://usephrased.com)

Micro-SaaS writing improvement tool with paywalled writing tools and free viral translators for growth.

`Next.js` `Claude Haiku` `Stripe` `Supabase` `Vercel`

### [ResearchGapFinder](https://researchgapfinder.buluthamali.com)

AI pipeline for detecting scientific knowledge gaps from biomedical literature, with a model-agnostic interface supporting Groq, Anthropic, and Ollama.

`Python` `Groq` `Anthropic` `Ollama`
